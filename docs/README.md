# AGMM Documentation
Author: Andreas Gkogkos

Technical documentation for the AGMM VCV Rack 2 plugin.

## About AGMM

AGMM is a collection of custom VCV Rack modules implemented in C++.

## Module Documentation (alphabetical order)
# Project Modules

Six moods (RESTING, WANDERING, HUNTING, CURIOUS, DANCING, STARTLED). Reacts to sound (three bands, onset, silence) but lives without it. Ten knobs with CV (FIELD, MOTION, VISC, SPIKES, SENS, GLOSS, INTEL, CURIO, FOOD, SIZE); buttons PAUSE/RESET/REACT/MOUSE; outputs ENV, FIELD, X, Y, ENERGY, EAT. Purple bioluminescence in dark rooms, cyan food pellets. |

| 22 | [Ladder](Ladder.md) | Shepard–Risset glissando VCO.
